# Atomic Bastion / 原子堡垒

2D 射击游戏。玩家操控角色向 8 个方向射击，击退并击杀敌人。  
Bastion（堡垒）强调据点防守与协同感，后续适合大房间、多据点的联机玩法。

一期工程只实现**单机**。联机与其余系统（货币、掉落、生命值等）待定。

## 玩法概要

| 项目 | 说明 |
| --- | --- |
| 类型 | 2D 射击 |
| 操控 | 单人或多人操控角色（一期仅单机） |
| 射击 | 上下左右 + 四个斜向，共 8 个方向 |
| 敌人 | 预计 3–5 种 |
| 武器 | 预计 5–10 种 |
| 其余系统 | 货币、掉落物、玩家 HP 等，待定 |

## 技术方向

本仓库为**前后端一体化**单体仓库。

- **前端**：Canvas 作为游戏本体（渲染与交互）
- **后端**：一期只保留目录，不实现服务逻辑
- **一期范围**：单机；后端与联机接口留待后续
