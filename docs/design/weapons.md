## 数值标尺

敌人血量尚未定稿。武器先按下列**临时档**对齐，避免互相抢定位。场地网格步长 48 像素。

| 档位 | 假设 HP | 设计用途 |
| --- | --- | --- |
| 杂兵 | 36 | 手枪两发、霰弹近距一枪、手雷范围内清掉 |
| 射手 | 54 | 步枪约五发、冲锋枪近距约八发 |
| 坦克 | 180 | 火箭约三发；手枪约十发兜底 |

含换弹后的持续输出：步枪最高（约 46）、冲锋枪次之（约 42）、手枪约 35。特殊武器单体持续更低，靠群体或穿透把总伤害打上去。

## 手枪

「守卫-54」型手枪，时下苏维埃各院校和研究所保卫科的常见制式武器，老保卫出门只别这一把。单发清楚、后坐可控，弹匣小，容错低。生存模式默认携带。

- 射速低，单发高，散布最小
- 杂兵两发、坦克十发，没有弹药时也能处理所有档位
- 按 `1` 切换

## 冲锋枪

「波波沙-41」冲锋枪，卫国战争中苏军列装最广的连发装备，弹幕如雨，一度是老兵的荣耀。单发弱，用来清近身潮。

- 理论 DPS 最高，散布大，中远距离浪费多
- 近距才能压过步枪；拉开距离应换枪
- 按 `2` 切换，按住空格连发

## 突击步枪

「曙光-74」突击步枪，战后守备团换装的制式长枪，中距稳、供弹足，据点换防人人一支。射速与伤害走中间值。

- 连发；弹匣伤害最高，适合一路点名射手
- 不穿透、不爆炸，换弹也不慢，作为默认「主力」
- 近战潮不如冲锋枪，贴脸爆发不如霰弹

## 霰弹枪

「门闩-12」霰弹枪，工厂纠察队破门清屋的短管泵动，近距一声，走廊里谁都站不稳。一次 7 粒弹丸。

- 点射；全中 49，杂兵一枪，两人并肩各吃 3–4 粒则双残
- 有效射程短，弹速慢，远了只剩一两粒
- 击退高，用来把冲锋线顶回去
- 群体来自**锥形多弹**，不是爆炸

## 手榴弹

「铁瓜-33」手榴弹，工兵口袋里最老实的家伙，引信一拧扔进人群，专管把挤成堆的敌人清掉。

- 点射投掷；弹速慢，引信 0.85 秒，给走位和预判
- 爆心 55，半径 108（约 2.25 格），范围内杂兵应直接死
- 弹匣按随身携带 3 枚计，装填慢
- 对坦克要扔 4 枚，不如火箭；对散兵不如步枪省弹

## 激光枪

「红线-7」激光枪，原子堡垒实验室的定向能样机，光束穿阵不拐弯，编制上仍写着试验。**命中后仍可再穿过 4 个目标**（一条直线最多 5 个）。

- 点射脉冲，散布 0，弹速接近瞬达，射程最长
- 单体 16，略低于手枪，打坦克慢
- 价值在于排队的杂兵 / 射手：三人一线等于每发 48
- 不爆炸、击退弱，不能当手雷用
- 能量匣 10 发，空匣回充偏慢，防止贯穿被无脑连刷

## 火箭筒

「锤头-2」火箭筒，反装甲分队的肩射破甲弹，一声闷响，坦克连同旁边的人一起开花。

- 点射；爆心 70，半径 78（约 1.6 格）
- 弹速中等，能看见弹体，误射近处会伤到自己（友伤规则仍待定）
- 三发打掉坦克；周围杂兵吃溅射
- 备弹 3、换弹最慢，不能当冲锋枪用

## 火焰喷射器

「炉心-3」火焰喷射器，巷战工兵随身的短管喷火，火流贴地舔过去，谁进锥里谁着。不因打中第一个敌人而消失。

- 连发；单跳 4、每秒 11 跳，单体 DPS 44
- 射程最短（170），锥内整排敌人同时掉血，清贴脸潮
- `penetration` 8：火流穿过人群；`blastRadius` 32 表示每段火焰的灼烧宽度
- 射手站在射程外时几乎废枪，必须靠走位把敌人引进锥里
- 燃料匣 48，喷空再灌，持续压制但有窗口

## 合理性

八种武器按「距离 × 单体 / 群体」错开，避免两把枪做同一件事。

1. **手枪是保底。** 准、够用、弹匣小。任何距离都能处理，但没有特长，玩家有理由换枪。
2. **冲锋枪赢在贴脸射速。** 理论 DPS 最高，散布惩罚中远距离。和步枪的分界是「能不能压住后坐并靠近」。
3. **步枪赢在命中与续航。** 单发与射速都居中，弹匣总伤最高，含换弹持续输出第一。中距离默认选择。
4. **霰弹是近距爆发，不是小火箭。** 群体靠 7 粒弹丸的空间分布：挤在一起才赚，散开就亏。泵动射速限制它不能替代冲锋枪扫射。
5. **手雷与火箭都爆炸，但分工不同。** 手雷半径更大、单发更低、带引信，专门打堆。火箭半径更小、单发更高、碰触即爆，专门打坦克并带一点溅射。两者备弹都只有 3，防止爆炸成为唯一解。
6. **激光只做直线穿透。** 单体故意低于手枪，避免「又准又痛又穿」。只有敌人重叠在射线上时才强，鼓励预判走位而不是对着坦克硬点。
7. **喷火只做短锥持续。** 单体 DPS 中等，乘上锥内人数才高。没有手雷的瞬间清场，也没有激光的超远射程，换的是「人进来就一起着」。
8. **特殊武器换弹都更痛。** 手雷 / 火箭 2.4–2.6 秒、喷火 2.2 秒、激光 1.7 秒。用完必须露出窗口，普通枪则更平滑。

暂不把近战刀、追踪导弹、地雷算进一期编制。友伤、火焰残留地面、手雷弹跳待战斗规则确定后再加字段。

## 数值字段

| 字段 | 含义 | 单位 |
| --- | --- | --- |
| model | 型号 | 文案，武器柜展示 |
| blurb | 背景介绍 | 30–60 字 |
| enabled | 是否默认进常用槽 | 布尔 |
| fireMode | 射击模式 | semi 点射 / auto 连发 |
| projectileId | 弹体索引 | 对应 projectiles.id |
| fireRate | 射速 | 发 / 秒 |
| magazineSize | 弹匣 / 备弹 / 燃料 | 发 |
| damage | 单发或爆心威力 | 伤害点 |
| reloadTime | 换弹时间 | 秒 |
| projectileSpeed | 弹速 | 像素 / 秒 |
| knockback | 击退 | 待定标尺 |
| spread | 散布 / 锥角 | 度 |
| penetration | 命中后还能再穿过的敌人数 | 0 为不穿透 |
| projectileCount | 单次射出数量 | 发 |
| range | 有效射程 | 像素 |
| blastRadius | 爆炸或灼烧半径 | 像素；0 为无范围 |
| fuseTime | 引信 | 秒；0 为碰触或即达 |

实现目录：`client/src/weapons/`。美术与角色共用 WebGL 正交烘焙。
