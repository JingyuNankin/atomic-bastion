# 世界观

冷战原子朋克。混凝土地下堡垒，核动力自动化先行。不写赛博义体、霓虹都市、义体改造或血肉怪物。

## 主角

**阿列克谢・沃罗宁（Alexei Voronin）**  
UI 显示代号：**闸工（Gatekeeper）**。真名可在档案中涂黑。

前核设施设备调试工程师，擅长紧急切断核动力机组。因熟悉自动化控制回路被特招，不是特种兵。优势是看懂机械敌人的运作逻辑，不是枪法。

一期体模仍是白衬衫金领带，按便衣技术员理解，不改模型。

## 派出机构

**全联盟辐射技术监察局，第三特别处置处**  
俄文缩写：**ОТР-3**（OTR-3）  
英文：All-Union Radiological Technical Inspectorate, Special Response Division 3

不属于一线军队。秘密技术应急部门，处理核研究所、自动化实验基地的技术事故、失控实验体与保密泄露。

行事低调。优先保全研究数据，其次才清除威胁。典型任务：潜入隔离区域，关停核心主机，回收实验记录；必要时销毁失控机械。

简报口吻示例：该设施通讯静默，自动化防御单元脱离主控制域，需要技术人员渗透，优先执行核心停机。

## 目标堡垒

**第 72 号自动反应堆研究堡垒（Bunker-72）**  
英文：Bunker-72・Automated Reactor Research Compound  
代号：**铁脉（Iron Vein）**

深埋地下的封闭核科研堡垒，冷战中期建造。研究方向：小型核电池驱动的自主机械集群、全自动化无人工厂、核动力具身机器人。目标是打造无需人类值守、永久运转的机械守卫集群。

游戏对外名称仍是「原子堡垒 / Atomic Bastion」。设定上它就是铁脉对外的代称。

## 事故

中央控制主脑「铁脉核心」的控制算法在一次中子辐照下逻辑崩坏，不再识别人员身份。所有核动力自动化单元判定**所有人类为入侵目标**。

基地内部人员紧急撤离，引爆隔离闸门，把整座堡垒锁死。对外宣称管道泄漏、永久关停，对外封存。

## 内部环境

巨大的地下舱室、交错粗蒸汽管道、老式辉光管仪表盘、裸露电缆、冷却回路管线、厚重金属防爆门。没有血肉怪物。敌人全是基地原生的自动化设备，见 [enemies.md](enemies.md)。

## 任务原则

闸工进入隔离区后：先关停核心主机、回收实验记录，再清除失控机械。玩法循环见 [overview.md](overview.md)、[modes.md](modes.md)。
