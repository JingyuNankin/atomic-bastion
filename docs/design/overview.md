# 定位与范围

**英文名**：Atomic Bastion  
**中文名**：原子堡垒

玩家扮演代号「闸工」的技术执行员，隶属全联盟辐射技术监察局第三特别处置处（ОТР-3）。任务是渗透第 72 号自动反应堆研究堡垒（代号铁脉）：铁脉核心遭中子辐照后逻辑崩坏，核动力自动化单元将所有人类判为入侵者。优先关停核心主机、回收实验记录，必要时销毁失控机械。

Bastion（堡垒）强调据点防守与协同。适合后续大房间、多据点的联机玩法。一期只实现单机。设定全文见 [setting.md](setting.md)。

## 核心循环（一期：生存模式）

1. 从菜单受领 ОТР-3 技术处置令，进入生存模式
2. 闸工在铁脉地下舱室中移动
3. 向 8 个方向射击
4. 击退 / 击杀源源不断的失控自动化单元
5. 以存活轮次为成绩（具体数值待定）

## 一期范围

- 单机
- 地图有限，用世界单位，不随屏幕变化（见 [scale.md](scale.md)）
- Canvas 作为游戏本体
- 首页菜单；目前仅开放生存模式
- 敌人预计 3–5 种
- 武器编制 8 种（目前实现手枪 / 冲锋枪）
- 不实现联机、后端服务、存档

## 非一期

- 保卫模式、收集模式（见 [modes.md](modes.md)）
- 存档 / 读档
- 多人房间、多据点协同
- 账号、匹配、服务端权威同步
- 货币、掉落、HP 等数值系统（见 [systems.md](systems.md)）
- 自定义皮肤、社区皮肤、自定名字与职业（官方执行员可在首页指派，见 [operatives.json](operatives.json)）
