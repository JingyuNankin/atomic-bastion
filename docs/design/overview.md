# 定位与范围

**英文名**：Atomic Bastion  
**中文名**：原子堡垒

Bastion（堡垒）强调据点防守与协同。适合后续大房间、多据点的联机玩法。一期只实现单机。

## 核心循环（一期）

1. 玩家操控角色在 2D 场景中移动
2. 向 8 个方向射击
3. 击退 / 击杀敌人
4. 在据点或场景中生存并清场（具体胜负条件待定）

## 一期范围

- 单机
- Canvas 作为游戏本体
- 敌人预计 3–5 种
- 武器预计 5–10 种
- 不实现联机、后端服务

## 非一期

- 多人房间、多据点协同
- 账号、匹配、服务端权威同步
- 货币、掉落、HP 等数值系统（见 [systems.md](systems.md)）
