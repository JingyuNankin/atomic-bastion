# 定位与范围

**英文名**：Atomic Bastion  
**中文名**：原子堡垒

Bastion（堡垒）强调据点防守与协同。适合后续大房间、多据点的联机玩法。一期只实现单机。

## 核心循环（一期：生存模式）

1. 从菜单进入生存模式
2. 玩家操控角色在 2D 场景中移动
3. 向 8 个方向射击
4. 击退 / 击杀源源不断的敌人
5. 以存活轮次为成绩（具体数值待定）

## 一期范围

- 单机
- Canvas 作为游戏本体
- 首页菜单；目前仅开放生存模式
- 敌人预计 3–5 种
- 武器预计 5–10 种
- 不实现联机、后端服务、存档

## 非一期

- 保卫模式、收集模式（见 [modes.md](modes.md)）
- 存档 / 读档
- 多人房间、多据点协同
- 账号、匹配、服务端权威同步
- 货币、掉落、HP 等数值系统（见 [systems.md](systems.md)）
