# 敌人

敌方全是第 72 号堡垒（铁脉）原生的核动力自动化设备。铁脉核心不再识别人员后，它们把所有人类判为入侵目标。没有血肉怪物，也不是外来部队。

预计 **3–5 种**。数值与行为待填，一期尚未实现。

| ID | 名称 | 定位 | 外观（设计） | 状态 |
| --- | --- | --- | --- | --- |
| E01 | 巡线机 | 近战冲锋 / 杂兵 | 核电池检修车，电缆拖在身后 | 待实现 |
| E02 | 电弧臂 | 远程火力 | 无人工厂焊接臂，间歇喷电弧 | 待实现 |
| E03 | 装卸机 | 坦克 / 高血量 | 重型吊运机，混凝土配重 | 待实现 |
| E04 | 滑轨车 | 快速骚扰 | 挂在滑轨上的运料小车 | 待实现 |
| E05 | 铁脉守卫 | 特殊机制（可选） | 核心舱外围的核动力具身机组 | 待实现 |

闸工的优势是看懂这些机组的回路，不是特种作战。每种敌人至少需要明确：

- 外观与碰撞体
- 移动与攻击行为
- 生命、伤害、击退抗性
- 出现场景与数量

武器文档里的「杂兵 / 射手 / 坦克」是血量档位，分别对应巡线机、电弧臂、装卸机这一档。

实现目录：`client/src/entities/`。
