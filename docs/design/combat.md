# 战斗

## 移动

WASD 八向移动（含对角线）。目前无走路动画，移动时只切换对应朝向的待机帧。

地图有限，尺寸用世界单位，不随屏幕变化。身高、移速和地图宽高都用同一单位。约定见 [scale.md](scale.md)。当前试玩舱 80 × 45 单位。窗口更大时地图居中，窗口更小时镜头跟着人，只看见其中一块。足底是边长 1.5 单位的正方形碰撞箱，整块留在地图内，脚不踩出边界。身体贴图可以伸出地图外。

## 射击

支持 **8 个方向**：

- 四向：上、下、左、右
- 斜向：左上、左下、右上、右下

方向由输入（键盘 / 手柄 / 后续可能的瞄准）决定。按 **空格** 沿当前朝向射击。弹道、射速、后坐与穿透按 [weapons.json](weapons.json) 配置；弹体用 `projectileId` 索引。激光画瞬时长束；火焰喷射器按住连续喷出约 25° 扇形火舌；手榴弹沿抛物线抛出，落地后向前滚动再爆炸。编制 8 种（见 [weapons.md](weapons.md)），战斗页「武器」柜左侧点选、右侧卡槽放入，自选 4 件。战场右侧 4 个槽，当前武器高亮；`1`–`4` 切换。左下角显示弹匣；换弹时右侧出进度条，装填中再按射击会提示「还在装填」。

## 命中与击退

- 子弹（或等价投射物）命中敌人后造成伤害，并可施加击退
- 击退方向默认沿射击方向；具体力度按武器与敌人抗性区分
- 击杀条件：敌人生命降至 0。血量见 [enemies.json](enemies.json)

机械鬣狗一步一顿地逼近，平均速度慢于执行员。进了撕咬距离就站住，咬中后把执行员沿远离方向推开一小段。地面单位互相有碰撞，无人机从它们上方飞过，不与之相撞；无人机自己的命中体积留在枪口高度。无人机靠近后闪红灯，再自爆。敌人从场地外进场。
