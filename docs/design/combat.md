# 战斗

## 移动

WASD 八向移动（含对角线）。场地有边界，不是无限地图。目前无走路动画，移动时只切换对应朝向的待机帧。

## 射击

支持 **8 个方向**：

- 四向：上、下、左、右
- 斜向：左上、左下、右上、右下

方向由输入（键盘 / 手柄 / 后续可能的瞄准）决定。弹道、射速、后坐与穿透按武器配置，见 [weapons.md](weapons.md)。

## 命中与击退

- 子弹（或等价投射物）命中敌人后造成伤害，并可施加击退
- 击退方向默认沿射击方向；具体力度按武器与敌人抗性区分
- 击杀条件：敌人生命降至 0（HP 数值体系待定）
