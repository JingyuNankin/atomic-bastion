# 一期：单机

目标：可游玩的 2D Canvas 射击原型（单机）。不包含联机与后端服务。

## 工程

- [x] 初始化仓库目录与 README
- [ ] 确定前端技术栈（Canvas 本体；打包 / 语言待定）

## 核心玩法

- [ ] 玩家移动

- [ ] 子弹与敌人碰撞
- [ ] 伤害、击退、击杀

## 内容量（目标）

- [ ] 敌人 3–5 种（设计 + 实现）
