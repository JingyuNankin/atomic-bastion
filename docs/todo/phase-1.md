# 一期：单机

目标：可游玩的 2D Canvas 射击原型（单机）。不包含联机与后端服务。

## 工程

- [x] 初始化仓库目录与 README
- [x] 确定前端技术栈（npm + Vite + TypeScript + Canvas）
- [x] 搭建 `client` 可运行的空白画布与游戏循环
- [x] 首页菜单（仅「开始游戏」进入生存模式）

## 玩家角色素材

待机 / 射击共用八向持枪姿势（空手，武器另叠）。由 WebGL 正交模型运行时烘焙，不加载位图。预览：`/tools/player-sheet.html`。

- [x] 玩家八向持枪待机（WebGL 方块模型，无钢盔、中性短发、白衬衫金领带）
- [x] 武器图（一期手枪 / 冲锋枪，按朝向叠到手上，不重绘角色）
- [ ] 走路八向（持枪姿势下的位移帧）
- [ ] 受伤姿势
- [ ] 抠除灰底 / 切帧，供 Canvas 使用

## 核心玩法

- [x] 玩家移动
- [x] 手枪 / 冲锋枪数值与 HUD
- [x] 8 向射击（空格；点射 / 连发）
- [ ] 子弹与敌人碰撞
- [ ] 伤害、击退、击杀

## 内容量（目标）

- [ ] 敌人 3–5 种（设计 + 实现）
- [ ] 武器 5–10 种（设计 + 实现）
- [ ] 至少一个可游玩场景

## 明确不做

- 联机、房间、据点协同
- 后端 API 与数据库落地
- 未定系统：货币、掉落、HP 等（见 `docs/design/systems.md`）
