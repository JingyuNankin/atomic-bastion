# 美术资源

规范与清单写在本目录。图像文件分两处，不要混放。

| 目录 | 用途 |
| --- | --- |
| [`assets/`](../../assets/) | 草稿（概念图、原图、未切片） |
| [`client/public/img/`](../../client/public/img/) | 前端正式图（构建后到 `dist/img/`） |

| 文件 | 内容 |
| --- | --- |
| [style-guide.md](style-guide.md) | 视觉方向与规格 |
| [asset-list.md](asset-list.md) | 需要制作的资源清单 |

两侧目录结构对齐：

```
sprites/   角色、敌人、投射物
tiles/     地块、据点、场景
ui/        HUD、菜单、图标
```

音频草稿仍在 `assets/audio/`。运行时音频目录尚未启用。
