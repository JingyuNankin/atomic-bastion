# 美术资源

规范与清单写在本目录；原始文件放在仓库根目录 `assets/`，运行时资源由前端构建流程拷贝或引用。

| 文件 | 内容 |
| --- | --- |
| [style-guide.md](style-guide.md) | 视觉方向与规格 |
| [asset-list.md](asset-list.md) | 需要制作的资源清单 |

原始资源目录：

```
assets/sprites/   角色、敌人、投射物
assets/tiles/     地块、据点、场景
assets/ui/        HUD、菜单、图标
assets/audio/     音效、音乐（若启用）
```
