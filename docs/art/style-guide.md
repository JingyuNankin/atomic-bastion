# 美术规格

视觉方向：冷战原子朋克。混凝土研究所、牛皮纸档案、针式打印件、五角星与朱红公章。不是赛博朋克。

玩家体模一期保持白衬衫金领带（闸工：便衣技术员，不是特种兵）。内部环境按铁脉地下堡垒：蒸汽管道、辉光管仪表、裸露电缆、重金属防爆门。敌人只做原生自动化设备。

## 色板

| 用途 | 色值 |
| --- | --- |
| 纸面 | `#d4c2a0` / `#c4ad86` |
| 油墨 | `#2c2418` |
| 公章 | `#a32020` |
| 混凝土 | `#6e6a62` / `#4a4740` |
| 外圈烟灰 | `#2a2722` |
| 警告 / 旧铜 | `#b8923a` |

禁止：青色辉光（`#7ec8ff`）、冰白字（`#e8f4ff`）、扫描线、外发光、品红加青霓虹。

运行时 token：`client/src/ui/theme.ts` 与 `client/src/style.css` 的 `:root`。

## 字体

不引入网络字体。

- 正文 / 标签：等宽打印机体，中文回退苹方 / 雅黑
- 标题：等宽或衬线加字距，像油印封面，不要科幻宽字距英文 logo

## 工程规格

| 类型 | 建议 |
| --- | --- |
| 透视 | 玩家 / 武器：WebGL 正交 45° 俯视，无透视；武器图层与角色共用相机与格尺寸 |
| 角色 / 敌人 | 正方形或矩形精灵，带透明通道 |
| 图块 | 统一 tile 尺寸（如 16 / 32 / 64 px，待定） |
| 格式 | PNG（精灵 / UI）；音频格式待定 |

装饰（五角星、公章、打印纸撕边、混凝土伸缩缝）用 CSS / Canvas 画，不另做 PNG。

## 命名

资源文件使用小写英文短横线，并与设计文档中的 ID 对应，例如 `e01-*.png`、`w01-*.png`。

草稿放 `assets/`，定稿拷到 `client/public/img/`，相对路径保持一致。
