# 美术规格

风格尚未锁定。下列仅作工程约束，避免后期无法接入 Canvas。

## 建议规格（待确认）

| 类型 | 建议 |
| --- | --- |
| 透视 | 玩家：WebGL 正交 45° 俯视，无透视 |
| 角色 / 敌人 | 正方形或矩形精灵，带透明通道 |
| 图块 | 统一 tile 尺寸（如 16 / 32 / 64 px，待定） |
| 格式 | PNG（精灵 / UI）；音频格式待定 |
| 色板 | 待定 |

## 命名

资源文件使用小写英文短横线，并与设计文档中的 ID 对应，例如 `e01-*.png`、`w01-*.png`。

草稿放 `assets/`，定稿拷到 `client/public/img/`，相对路径保持一致。
